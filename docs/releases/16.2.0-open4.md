# OpenAmigaGCC 16.2.0-open4

GCC 16.2 for AmigaOS 3.x (`m68k-amigaos`). Everything in open3 remains. Open4 adds the wrong-code and libnix fixes merged since open3.

## New since open3

| Item | open3 | open4 |
| --- | --- | --- |
| `move.b (a2)+,(a0,a2.l)`: a move whose source steps a register addressed its destination through it (GCC 15's late-combine, PR123853) | each element landed one place late at `-O2` | never generated: `patches/gcc/0013` ([docs](../autoinc-move.md)) |
| `strcat` into a local array, inlined at `-O1`/`-O2` for 68020 and up | wrote to an absolute address (`virtual-stack-vars` left after vregs) | addresses the array: `patches/gcc/0014` ([docs](../vregs-address.md)) |
| `strtol`/`strtoul` on empty or whitespace-only input | left `endptr` unset | `endptr` is the input: `patches/libnix/0008` ([docs](../libnix-strtol-endptr.md)) |
| Compiler identity | `OpenAmigaGCC 16.2.0-open3` | `OpenAmigaGCC 16.2.0-open4` |

## Known

- The toolchain needs glibc 2.38 or later.
- The shared `libnix4.library` still does not link; normal static programs do not need it.
- For ARM64 Linux, use 16.2.0-open1's toolchain until an ARM64 build of open4 is made.
